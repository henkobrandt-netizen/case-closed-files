# Case Closed Files

Code and finished media for the Case Closed Files YouTube channel: true stories of
history's greatest cons and heists, animated and told like thrillers.

- `pipeline/` the render system (skia-python + ffmpeg + Kokoro TTS). Start with `PLAYBOOK.md`.
- `episodes/<id>/` one folder per episode: script, scenes, metadata, sources.
- `media/<id>/` finished long video, short and thumbnails (served to vidIQ from here).
